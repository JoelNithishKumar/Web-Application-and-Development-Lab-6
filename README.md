# Sunrise & Sunset Dashboard
This project is a responsive, interactive web application that displays sunrise, sunset, dawn, dusk, day length, solar noon, and timezone data for today and tomorrow based on the selected location or your current geolocation.

Built with HTML, CSS, and JavaScript, the app uses the SunriseSunset.io API to fetch real-time astronomical data and presents it in visually appealing gradient boxes with relevant icons.

# Features

>Choose from 10 global cities or use your current location

>View data for both today and tomorrow

>Weather-themed gradient color design

>Mobile-friendly and responsive layout

# Technologies Used
HTML5

>CSS3 

>JavaScript

>Geolocation API

>SunriseSunset.io API
